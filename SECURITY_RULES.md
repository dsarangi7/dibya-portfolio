# Security Rules

This portfolio must only contain public-safe content and must never expose confidential or proprietary information.

## Rules
- Do not include any confidential AYK source code.
- Do not include private company documents or internal engineering files.
- Do not include real customer data, customer names, or customer-specific details.
- Do not include internal file paths, server names, or environment variables.
- Do not include proprietary screenshots unless the image is fully sanitized and abstracted.
- Use synthetic examples only for dashboards, analytics visuals, and data stories.
- When describing projects, keep the language high-level and focus on architecture, problem solving, and outcomes.
- Use only sanitized public-safe descriptions from the existing `PROJECTS.md` content.
