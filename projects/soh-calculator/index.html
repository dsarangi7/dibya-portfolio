Battery Health Analytics

SOH Calculator

I built a web tool that turns raw battery string logs into cell-, module-, and string-level state-of-health results and a finished customer report. Work that took about a week by hand now takes minutes.

← Back to home

Built for internal engineering use. Calculation constants, cell data, and customer details are left out; the plots here are synthetic.

The problem

SOH checks ran through a chain of MATLAB scripts. An engineer picked the test windows for every string by hand, re-ran the scripts for each bank, then built the customer report by copying tables and plots into Word. A full project took about a week, and every manual step was a chance for an inconsistency.

What changed

I traced the existing MATLAB workflow line by line and rebuilt it as a tested Python service with a browser front end. One project folder now runs as a batch, and each run is saved with its inputs, tables, plots, and calculation log. The report comes out ready to send.

How SOH is calculated

The method is capacity-based: measure the charge that went in, and work out what fraction of the cell’s range that charge covered.

SOH = ( ∫ I dt ÷ ΔSOC ) ÷ Crated

  1. 01

    Ingest

    Reads each string's CSV or Excel log and detects the timestamp, current, per-cell voltage, and temperature channels by name. A folder scan finds every string in a project, across banks.

  2. 02

    Window detection

    Finds the longest sustained charge segment as the capacity window, then the last stable-current run inside it as the C-rate window. Engineers can still zoom and click to pick both windows by hand.

  3. 03

    Coulomb counting

    Integrates current over the capacity window to get the charge the cells actually absorbed, in Ah. The mean current over the C-rate window gives the test C-rate.

  4. 04

    C-rate-matched OCV–SOC lookup

    Interpolates between the cell type's OCV curves to match the measured C-rate, then converts each cell's start and end voltage into SOC.

  5. 05

    SOH estimate

    Charge ÷ ΔSOC gives each cell's usable capacity. Divided by rated capacity, that is its state of health.

  6. 06

    Temperature correction

    Applies a temperature-dependent factor to the end voltage against a low-rate reference curve, then recomputes ΔSOC and SOH. Results are shown before and after correction.

  7. 07

    Aggregate & report

    Rolls cell results up to modules and strings, plots them, and fills a Word report template with the correct system diagram, tables, and figures for that configuration.
